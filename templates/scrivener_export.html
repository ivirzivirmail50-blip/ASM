ℹ About Scrivener Export

This generates a ZIP file containing a .scriv folder structure compatible with Scrivener's import format. Each chapter becomes a .scrtext file with metadata headers (title, synopsis, keywords, status, word count). A binder.xml file defines the project structure (Draft folder with chapter documents).

To import into Scrivener: Unzip the downloaded file, then in Scrivener use File → Import → Import… and select the .scriv folder. The chapter structure and metadata will be preserved.

Note: This is a simplified export. Complex Scrivener features (compile settings, snapshots, research folders) are not included.
