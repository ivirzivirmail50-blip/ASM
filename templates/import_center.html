Character JSON Format

Each file should be a JSON array of character objects. Example:

[
  {
    "name": "Elara Vance",
    "role": "protagonist",
    "age": "27",
    "gender": "Female",
    "aliases": ["El", "The Veiled One"],
    "physical": "Tall, raven-black hair, violet eyes",
    "psychology": "Methodical, curious, fears loss of control",
    "background": "Raised in Hollowmere by her mother",
    "philosophy": "Knowledge must be earned",
    "voice": "Measured sentences, formal when stressed"
  }
]

Required: name. All other fields optional. You can also export characters as JSON from a character's detail page and re-import here.

📦 Migrating from a previous version?

If you have data from an older version of Absolute Story Manager:

  1. JSON Export/Import — Go to Settings → Import/Export → Export JSON. In the new version, use Import JSON to restore everything.
  2. Backup Restore — Go to Settings → Backup → Create Backup (creates a ZIP). In the new version, Settings → Backup → Restore from backup.
  3. Manual File Import — Use this Import Center to re-upload your chapter files (TXT, DOCX, etc.) and world entry files.
Note: JSON Export/Import preserves everything (chapters, characters, world, plans, settings). Backup Restore replaces the entire database. Manual import only imports file contents.
